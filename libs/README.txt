# Dependencies

Place the following JAR files in this directory:

1. **hytaleserver.jar** (or hytale-server.jar)
   - From your Hytale server installation

2. **civiccore-economy-1.0.1-simplified.jar** (or similar)
   - Your economy plugin JAR

These files are needed for compilation but will NOT be bundled into the final plugin JAR.
They are provided by the server at runtime.
